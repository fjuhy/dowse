# Dowse engine fork

This fork maintains the search engine used by [IndexRay](https://github.com/fjuhy/indexray). It extends [upstream Dowse](https://github.com/ltspace/dowse) with Korean text processing, Outlook archive and attachment indexing, and incremental Markdown export.

- [IndexRay Windows downloads and guide](https://github.com/fjuhy/indexray/releases/latest)
- [Engine crate](crates/dowse)
- [Upstream project](https://github.com/ltspace/dowse)

IndexRay pins the engine to a specific Git revision. The fork retains the upstream copyright and license notices; the fork is distributed under [MIT](LICENSE-MIT).
